# Buurt Toolbox — UX Dummy

Een klikbare GitHub Pages-prototype met:

- vernieuwde professionele UX/UI
- gebiedsanalyse-animatie
- transparante reasoning per locatie
- 8 kansrijke locaties
- scorekaarten en opgaven
- kaartfilters
- lokale chatinterface zonder API-key
- interventiebibliotheek

## Publiceren op GitHub Pages

1. Pak het ZIP-bestand uit.
2. Upload `index.html`, `styles.css` en `app.js` naar de root van je repository.
3. Ga in GitHub naar `Settings → Pages`.
4. Kies `Deploy from a branch`.
5. Kies branch `main` en map `/(root)`.

De kaart gebruikt Leaflet en OpenStreetMap. Alle inhoudelijke scores zijn voorbeelddata.
