# Buurt Toolbox Analyse Dummy

Upload `index.html`, `styles.css` en `app.js` naar de root van je GitHub-repository.

Ga daarna naar **Settings → Pages → Deploy from a branch → main → /(root)**.

De demo bevat een analyseanimatie, gebiedsscores, vijf opgaven, acht kanspins, kaartfilters en interventiedetails. Alle analyses zijn voorbeelddata.
